# Workout App

筋トレの記録・目標管理・成長の可視化を目的としたWebアプリです。

## 概要

自分のトレーニング内容を記録し、過去の記録を振り返ることで、
トレーニングによる成長を実感できることを目的としています。

個人での利用を想定していますが、ユーザー登録・ログイン機能を実装し、
複数のユーザーがそれぞれ自分のトレーニングデータを管理できる構成を目指しています。

また、実装から始めるのではなく、

**要件定義 → 設計 → 実装 → テスト → 改善**

という開発工程を経験することを目的として開発しています。

# 要件定義

## アプリの目的

筋トレの記録を残し、過去のトレーニングや体重の変化を確認することで、
自分の成長を可視化し、トレーニングのモチベーションにつなげる。

## 想定ユーザー

筋トレを継続しており、

- トレーニング内容を記録したい
- 過去の記録を確認したい
- 目標を設定したい
- 自分の成長を確認したい

というユーザーを想定しています。

---

# 主な機能

## ユーザー機能

- ユーザー登録
- ログイン
- ログアウト
- ユーザーごとのデータ管理

## トレーニング記録

- トレーニング日を記録
- トレーニングのコメント・メモを記録
- 1回のトレーニングに複数の種目を登録
- 1つの種目に複数のセットを登録
- セットごとの重量・回数を記録

## 記録管理

- トレーニング履歴の確認
- トレーニング記録の編集
- トレーニング記録の削除
- 種目の編集・削除
- セットの編集・削除

## 目標管理

- 今後の目標を設定
- 1ヶ月後の目標を設定
- 複数の目標を管理

## 体重管理

- 日付ごとの体重を記録
- 過去の体重を確認

## 成長の可視化

- トレーニング記録の確認
- 体重の推移をグラフ化
- トレーニング内容の推移を確認

## ホーム画面

ログイン後のホーム画面で、

- 今日の日付
- 現在の目標
- 1ヶ月後の目標
- 体重
- 当日のトレーニング状況

などを確認できるようにする予定です。
